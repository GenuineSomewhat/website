How It Works

  1. Upload a file - Any type of file (audio, image, code, etc.)
  2. Specify folder path - Where should the file go in the bot? (e.g., /Audio)
  3. Create patch - The file is encoded into a PNG image
  4. Download - Use the patch image with the bot's !patch command

Using Patches

Send the patch image to the bot with the !patch command:

!patch

The bot will extract and place the file in the specified folder automatically.
